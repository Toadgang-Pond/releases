# Public release checklist

- [ ] Human-approved release scope, owner, and version
- [ ] Exact source commit and repository recorded
- [ ] Clean worktree; no force-push; reviewed source provenance
- [ ] Exact-head CI green (with run IDs recorded)
- [ ] Security review complete; no private material included
- [ ] License and third-party notices approved
- [ ] Build artifacts generated from approved source
- [ ] Artifact SHA-256 checksums independently verified
- [ ] Release notes, limitations, installation, and rollback instructions prepared
- [ ] Explicit final human approval recorded
- [ ] Version tag and GitHub Release published
- [ ] Public download and checksum links verified
- [ ] Release index updated to verified links

If any item fails or cannot be verified: **HOLD**.
